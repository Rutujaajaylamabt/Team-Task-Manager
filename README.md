# 🚀 Team Task Manager (Full-Stack Backend)

## 📌 Project Description
Team Task Manager is a backend system built using Spring Boot that allows users to manage projects and tasks efficiently. It includes authentication, project management, task tracking, and a dashboard for analytics.

---

## 🔥 Features

- 🔐 User Authentication (Signup & Login)
- 📁 Project Management (Create & View Projects)
- ✅ Task Management (Create & Track Tasks)
- 📊 Dashboard (Total, Completed, Pending Tasks)
- 🗄️ MySQL Database Integration
- 🌐 REST APIs

---

## 🛠️ Tech Stack

- Java (Spring Boot)
- MySQL
- Spring Data JPA
- REST API
- Maven
